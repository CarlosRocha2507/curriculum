## Tecnologias

- **HTML5** — estrutura e conteúdo do currículo.
- **CSS3** — estilos personalizados, layout responsivo e formatação para impressão.
- **JavaScript** — interação com o botão de impressão.
- **Tailwind CSS** — classes utilitárias para composição do layout, com CSS compilado incluído no repositório.
- **Font Awesome** — biblioteca de ícones referenciada através de CDN.

## Como visualizar

Abrir o ficheiro `index.html` num navegador. Não é necessário instalar dependências nem iniciar um servidor. O carregamento dos ícones externos requer ligação à internet.

Para imprimir ou guardar uma cópia em PDF, usar o botão **Imprimir / Guardar PDF**. Nas opções do navegador, selecionar papel A4, escala de 100%, desativar cabeçalhos e rodapés e ativar gráficos de fundo.

## Organização

- `index.html` — conteúdo do currículo.
- `style.css` — estilos personalizados e regras de impressão.
- `scripts.js` — interações em JavaScript.
- `tailwind.css` — estilos compilados do Tailwind CSS.
- `tailwind.input.css` — ficheiro de entrada para compilação do Tailwind CSS.
- `images/` — imagens utilizadas no currículo.
